# Project provenance

Relay grew out of exploring reliability concerns in a voice-assistant interview exercise. The scheduling application, browser dashboard, tests and operating tools in this repository were subsequently implemented as a separate project.

This repository excludes the earlier exercise's starter code, original voice CLI, integration wrappers, instructions, personal interview notes and inherited tests. The new application does not import those files. Earlier materials remain outside this repository in the author's local reference workspace.

The validation counts in this repository refer only to Relay's own tests. No fabricated development history or duration is asserted.

Third-party libraries are installed through the dependency manifest and lockfile, and retain their respective licenses. No open-source license for Relay has been selected; publication should not be interpreted as an unrestricted license grant.
